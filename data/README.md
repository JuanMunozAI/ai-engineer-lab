# Fake claims data (Project 2)

Everything here is **fictional**. Names like "Maria Testcase" are made up on purpose. No real patient data. Do not add any.

- `patients.json`: 17 fake patients (plan, birth date, member-since date, past visits)
- `claims.json`: 20 fake insurance claims waiting to be sent
- `answer_key.json`: the correct verdict for each claim (OK or PROBLEM, and why). The agent never sees this file; we use it to grade the agent.

The rules come from the office docs in `docs/` (plan summaries, claim submission, pre-authorization, CDT code notes). "Today" for these claims is 2026-11-22.
