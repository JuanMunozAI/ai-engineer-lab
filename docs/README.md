# Lakeside Family Dental: Fake Office Documents

These 30 documents describe a **fictional** dental practice. Every name, phone number, address, plan, fee and program is made up for training. Insurance plans (SunCoast, BlueWave, GuardStar, SunState Kids), the lab, the software and the financing company are fictional. CDT codes are real code numbers with plain-English notes; fees and rules here are invented.

**No real patient data. Do not add any.**

Folders:
- `policies/` office rules (hours, cancellations, payments, privacy, emergencies, minors)
- `insurance/` plan summaries and billing procedures
- `clinical/` clinical workflows
- `codes/` CDT code notes
- `faq/` front desk and patient FAQs
- `staff/` HR and software guides

Some facts deliberately differ between documents (for example, cleaning frequency rules per plan) so the assistant has to pick the right source.
