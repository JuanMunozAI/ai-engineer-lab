# Sterilization and Infection Control

- All reusable instruments are cleaned in the ultrasonic cleaner, bagged, and run through the autoclave.
- Each autoclave pouch is labeled with the date and the operatory number.
- Run a **spore test** on each autoclave **every week** (Monday). Log results in the sterilization binder. A failed test means the autoclave is taken out of use until a repeat test passes.
- Wipe down operatory surfaces with hospital-grade disinfectant between every patient.
- Waterlines are shocked monthly and tested quarterly.
- Staff wear masks, eye protection and gloves for all patient care. Change gloves between patients.
- Sharps go only in the red sharps containers. Swap a container when it is **3/4 full**.
