# CDT Code Notes: Diagnostic (D0100 to D0999)

Training notes for staff. Short descriptions only; the doctor chooses the code.

| Code | Plain-English meaning | Office notes |
|---|---|---|
| D0120 | Periodic exam, existing patient | Done at recall visits |
| D0140 | Limited exam, problem-focused | Emergency visits; office fee $95 |
| D0150 | Comprehensive exam | New patients, or existing patients not seen in 3+ years |
| D0210 | Full-mouth X-ray series | See X-ray guidelines |
| D0272 | Two bitewing X-rays | |
| D0274 | Four bitewing X-rays | Most adults |
| D0330 | Panoramic X-ray | |

Common mistake: billing D0150 for an existing patient who was seen within the last 3 years. Use D0120 instead.
