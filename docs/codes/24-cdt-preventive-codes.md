# CDT Code Notes: Preventive (D1000 to D1999)

| Code | Plain-English meaning | Office notes |
|---|---|---|
| D1110 | Cleaning, adult (age 14+) | Healthy gums only |
| D1120 | Cleaning, child (under 14) | |
| D1206 | Fluoride varnish | Check plan age limits (SunCoast: under 16) |
| D1351 | Sealant, per tooth | Tooth number required on the claim |

Common mistakes:
- Billing D1110 for a patient with active gum disease. They need D4341/D4342 first.
- Billing D1110 for a patient on periodontal maintenance. Use D4910.
- Missing tooth number on D1351.
