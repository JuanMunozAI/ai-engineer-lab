# CDT Code Notes: Restorative (D2000 to D2999)

| Code | Plain-English meaning | Office notes |
|---|---|---|
| D2391 | Tooth-colored filling, one surface, back tooth | Tooth number and surface required |
| D2392 | Tooth-colored filling, two surfaces, back tooth | Tooth number and surfaces required |
| D2740 | Porcelain/ceramic crown | Pre-op X-ray and narrative required; bill on seat date |
| D2950 | Core buildup | Pre-op X-ray required; usually done with a crown prep |

Surface letters: M (mesial), O (occlusal), D (distal), B (buccal), L (lingual). A two-surface filling like "MO" uses D2392, not D2391.

Office fees (self-pay): D2391 $185, D2392 $235, D2740 $1,250, D2950 $295.
