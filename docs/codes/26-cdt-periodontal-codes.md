# CDT Code Notes: Periodontal (D4000 to D4999)

| Code | Plain-English meaning | Office notes |
|---|---|---|
| D4341 | Deep cleaning (scaling and root planing), 4 or more teeth in a quadrant | Quadrant required: UR, UL, LR, LL |
| D4342 | Deep cleaning, 1 to 3 teeth in a quadrant | Quadrant required |
| D4910 | Periodontal maintenance | After deep cleaning; every 3 months |

- Claims for D4341/D4342 need perio charting showing pockets of 4 mm or more, plus recent X-rays.
- Most insurers allow D4341/D4342 once per quadrant every **24 months**.
- Office fees (self-pay): D4341 $245 per quadrant, D4342 $175 per quadrant, D4910 $160.
